# 焦段统计 v0.3.0

修复 Apple 相册中无法按系统星级统计照片的问题。过去列表仅包含普通相簿，选择名为「★★★★★」的相簿时会读取该相簿的实际成员，不会自动匹配系统五星照片。

新版在「Apple 相册 → 照片范围」新增 **5 星照片 · 整个图库**，以及 1–4 星和未评级范围，直接读取系统评级。原有相簿保持独立，CSV 也会记录所选星级范围。

使用方式：连接照片图库，选择「5 星照片 · 整个图库」，点击开始统计。若原件尚在 iCloud，可在更多设置中允许下载。iPhone 的评级需要先同步到 Mac。

系统星级筛选需要 macOS 27 或更新版本；其他功能继续支持 macOS 13 及更新版本。下载包适用于 Apple Silicon，采用本机临时签名，尚未进行 Developer ID 签名或公证。

验证：自动化回归全部通过；在 macOS 27.0.1 的真实图库中核对五星照片数量与系统照片一致，本机原件统计通过。iCloud 下载已验证启动、部分读取与取消；完整云端批次及 macOS 27.2 真机未单独复测。

隐私：应用只读取照片与评级，不修改图库、不上传照片。发布包只包含应用，核查截图与真实图库数据不随代码或 Release 上传。
