# 焦段统计 v0.3.1

修复系统星级范围与旧星形相簿容易混淆的问题，并将常用统计选项移到一级界面。

- macOS 27 及更新版本隐藏没有可访问照片的旧星形相簿入口，保留实际可用的系统星级范围。
- 有照片的星形相簿仍可选择，明确标为「普通相簿 · ★★★★★」，与「5 星照片 · 整个图库」区分。
- 不删除、不重命名、不修改系统图库中的任何相簿或照片；旧系统保留原有相簿入口。
- 「焦距口径」和「显示全部焦段」直接显示在统计方式中，移除「更多设置」折叠。
- iCloud 下载开关直接放在 Apple 相册来源中，默认开启；保留用户在本次会话中手动关闭的选择。

检查了 macOS 27 公开 PhotoKit API：无法独立查询焦距与镜头 EXIF，因此保留原件读取流程，未改用缩略图或私有数据库捷径。

使用系统五星照片时，选择 **Apple 相册 → 照片范围 → 5 星照片 · 整个图库**。

验证：自动化回归全部通过；真实图库菜单确认重复空星形入口已消失，五星照片全部读取成功，读取失败和待下载均为零；一级设置、默认下载与最小窗口操作通过。实测 macOS 27.0.1，未单独复测 27.2。

Apple Silicon，macOS 13 及更新版本；系统星级需要 macOS 27。应用采用临时签名，尚未进行 Developer ID 签名和公证。发布包不包含真实图库数据或截图。
