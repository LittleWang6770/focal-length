# 焦段统计 v0.4.0

支持同时统计多个本地文件夹，可混合本机磁盘与外置磁盘。

- 「照片来源」改为文件夹列表，可一次添加多个目录，也可继续追加。
- 勾选一项或多项后批量移除，支持全选。勾选仅用于管理路径，统计合并列表中的全部来源；移除不删除源照片。
- 各目录分别记住只读访问权限，重启恢复列表，自动迁移旧版单目录书签。
- 父子目录重叠或重复添加时，同一路径照片只计一次。扫描范围对每个目录生效。
- 一个目录离线时报告原因，其余可访问来源继续统计；CSV 列出所有来源路径。

验证：合成照片回归覆盖多目录合并、重叠去重、离线来源、权限书签恢复/迁移、单项及批量移除。原生界面实测多选添加、继续追加、重启恢复、批量移除，以及最小窗口的结果、运行和停止状态。

Apple Silicon，macOS 13 及更新版本；系统星级筛选需要 macOS 27。应用采用临时签名，尚未进行 Developer ID 签名或公证。发布包只包含应用，不包含真实照片、书签或本机核查数据。
