# 验证记录

## v0.3.0：系统星级筛选

2026-10-07，Apple Silicon 本机，macOS 实测版本为 27.0.1，使用 macOS 27.0 SDK，部署目标保持 macOS 13。未单独在 macOS 27.2 或旧系统真机复测。

- `zsh scripts/verify.sh` 通过：新增五星/未评级/全部范围、旧系统不显示星级入口、同名相簿独立、CSV 范围和重置选择回归；原有 JPEG/PNG/HEIC、统计分母、取消等验证全部通过。
- 真实图库只读核查：系统照片的五星筛选数量与新版匹配数量一致，视频未混入照片总数。旧版选择同名普通相簿得到空结果，新版明确选择「5 星照片 · 整个图库」后成功读取本机原件并生成镜头/焦段看板。
- 本机读取模式下，成功读取数与 iCloud 待下载数之和等于五星匹配总数；没有读取失败。
- 打开 iCloud 下载后扫描继续推进；停止后恢复控件、停止倒计时并显示未完成状态。因为完整云端批次耗时较长，本次只验证下载启动、部分读取和取消，没有宣称完整云端批次通过。
- 使用者完成新版系统照片授权后，应用正常列出原有相簿及 1–5 星/未评级范围；没有更改照片或评级。
- 980 × 700 最小窗口验证新增范围控件、侧栏滚动、运行禁用与停止按钮；真实截图仅保留在被忽略的 `artifacts/`。
- Release ZIP 只含应用包；解压后通过 `codesign --verify --deep --strict`。未嵌入照片路径、用户邮箱、核查日志或截图。

接口依据：[Apple PHAsset.rating](https://developer.apple.com/documentation/photos/phasset/rating-swift.property) 及 macOS 27 SDK 的 `PHAsset.h` / `PhotosTypes.h`。评级由系统图库读取，不从星形相簿名或个人收藏推断。

## v0.2.0：首版验证

2026-09-28，Apple Silicon 本机，Swift 工具链，macOS 13 部署目标。

## 自动化验证

`scripts/verify.sh` 编译扫描器与统计模型测试。系统 HEIC 编码器在受限沙盒中无法生成图片，随后在获准的普通本机环境运行 `build/verify`，全部通过。只在项目 `build/fixtures` 生成 64 × 64 的合成图片，不访问真实照片或图库。

- ImageIO 实际读取 JPG、JPEG、PNG、HEIC；标准 EXIF、镜头字段与等效焦距一致。
- 当前文件夹：6 张成功、1 张损坏；递归：7 张成功、1 张损坏。
- 递归结果：5 张有等效焦距，6 张有实际焦距；只有实际焦距的照片不会被误报为等效。
- 隐藏文件、符号链接与符号链接循环、`.photoslibrary` 包均跳过。
- `LIVE.HEIC + LIVE.MOV` 只计一张静态照片。此项验证的是文件夹中的文件对，不能代替 PhotoKit Live Photo 资产验证。
- 24–70 GM II 组共 3 张，其中 49 与 51 mm → 50 mm 共 2 张，占该镜头组 66.7%；35 GM 独立分组。
- 镜头组与未知组之和等于成功读取数；筛选焦段分母变化时，镜头总览保持来源总分母。
- 精确模式 35.5 → 36 mm；标准序列外的 6.86 与 800 mm 保留原值。
- 空文件夹、不存在的来源、任务取消、示例与真实数据隔离。
- CSV 引号/逗号与公式前缀处理、筛选条件记录。

## 原生窗口实测

使用 Computer Use 操作构建后的 `build/焦段统计.app`，只选择上述合成目录。

- 通过系统文件夹选择器授权后统计，结果与自动测试相同：7 张成功、5 张可用等效焦距、3 个已识别镜头型号、1 张读取失败。
- 退出并重新启动应用后，恢复之前的文件夹，无需重复选择；点击开始再次得到同样结果。
- 结果中的长目录名与路径中间省略，完整内容可悬停查看。
- 980 × 700 最小窗口实测；两栏可分别滚动，高级设置展开后可访问全部设置，开始/停止固定可见。
- 合成场景中的运行状态锁定来源与统计选项，进度和剩余时间更新；停止后倒计时终止，恢复控件，进度不显示完成。
- 失败场景显示独立提示与重新选择入口；已完成场景显示统计结果。全部示例场景在顶部标明合成数据。

上述场景的截图仅保留在本机 `artifacts/`，不随仓库上传，避免暴露界面中的本机路径。

## 尚未验证的边界

- PhotoKit 代码已经编译，数据资源的 ImageIO 读取路径使用合成 JPEG 字节测试通过；尚未在真实或隔离测试图库中完成授权、相簿枚举、Live Photo/RAW 配对、iCloud 下载及中途取消的端到端验证。没有为验证而授权或操作用户真实图库。
- 未收集各相机厂商实际输出样本；目前依赖标准 EXIF / ImageIO 辅助镜头字段，厂商私有字段未识别时显示未知。
- 没有十万张规模性能测试；未验证 Intel Mac 与 macOS 13 真机运行。
- 应用是本地临时签名，尚未使用 Developer ID 签名和公证。文件夹书签恢复已在同一本地构建的两次启动间实测，签名身份变化后的系统权限保持不能据此保证。
