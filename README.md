# 焦段统计

轻量、只读的原生 Mac 照片焦段与镜头统计工具。SwiftUI / AppKit + ImageIO + PhotoKit，无第三方运行依赖。

应用位置：**`build/焦段统计.app`**，双击即可使用。当前构建为 Apple Silicon，macOS 13 或更新版本。

## 使用

1. 选择本地文件夹，或连接 Apple 相册。文件夹会保存只读访问书签；相册首次使用时通过系统申请权限。
2. 文件夹可选当前层或包含子文件夹；Apple 相册可选所有照片、一个相簿，或在 macOS 27 及更新版本选择系统星级。
3. 开始统计，在看板中点击镜头即可查看它的焦段分布。可切换标准/精确焦段和等效/实际焦距。

支持 JPG/JPEG、PNG、HEIC/HEIF。Live Photo 只计静态照片资源，MOV 不重复计数。没有 EXIF 的照片仍计入读取成功的照片总数，缺失焦距、未知镜头单列；损坏、云端未下载和不支持的相册资源不混入分母。

镜头识别读取标准 EXIF 与系统提供的辅助镜头字段，未识别时如实显示，不猜测镜头型号。等效焦距仅使用照片明确记录的数值，缺失时可切换实际焦距。不根据相机型号猜画幅，也不将实际焦距冒充等效焦距。

Apple 相册默认允许从 iCloud 按需下载原件，可直接在「照片来源」中关闭。读取原件可能传输完整压缩照片数据，一次处理一张，单资源上限 256 MB。只有 RAW 的资产暂不支持。「焦距口径」与「显示全部焦段」直接显示在「统计方式」中，无需展开更多设置。

当前公开 PhotoKit 接口没有独立提供焦距、等效焦距和镜头型号。macOS 27 的 `PHAssetExtendedMetadata` 仅增加说明、原始文件名与关键词，并不能替代相机 EXIF。为保持统计口径可靠，应用继续从原件读取；云端原件未在本机时仍需下载，不用缩略图缺失的 EXIF 冒充原件信息。

### 统计系统五星照片

在「Apple 相册 → 连接照片图库 → 照片范围」选择 **5 星照片 · 整个图库**，然后开始统计。也可选择 1–4 星或未评级；每项只匹配该星级。星级使用 macOS 27 新增的 PhotoKit `PHAsset.rating`，与照片文件中的 XMP/EXIF、个人收藏以及名叫「★★★★★」的相簿相互独立。普通相簿仍按真实成员统计，不根据名称猜测内容。

为避免重复入口，macOS 27 及更新版本不列出没有可访问照片的「★」至「★★★★★」旧相簿；有照片的同名相簿标为「普通相簿 · ★★★★★」。这只整理本应用的选择列表，不删除或重命名系统相簿。

星级范围读取当前系统照片图库中可访问的照片，遵循 PhotoKit 默认隐藏照片/连拍代表图规则，不计视频；每次重新统计都会重新读取星级。iPhone 的评级需先同步到此 Mac 的系统照片图库。如果已经匹配但原件在云端，保持「照片来源 → 允许从 iCloud 下载原件」开启即可。macOS 13–26 继续提供原有功能，不显示系统星级范围。

CSV 可导出当前焦段筛选结果与整个来源的镜头分布；导出中包含分母、筛选条件、缺失和未分析计数。诊断列表最多保留前 100 条。应用不写入、删除或上传照片。

「示例与帮助」提供独立合成数据预览及空白、运行、完成、停止、失败状态，示例模式在顶部明确标注，退出后清除示例结果。

## 构建与验证

```sh
zsh scripts/build.sh
zsh scripts/verify.sh
```

需要带 macOS 27 SDK 的 Xcode Swift 工具链；构建仍以 macOS 13 为最低运行版本。验证程序仅在 `build/fixtures` 创建合成图片，不访问真实照片或相册。受限制的执行沙盒可能阻止系统 HEIC 编码器生成测试图片，此时需在普通本机终端运行验证。程序本身读取 HEIC 不需要这一步编码。

本机使用临时签名，尚未进行 Developer ID 签名和公证。当前应用重启后的文件夹访问恢复已验证；正式分发应保持 Bundle ID 与稳定签名身份，权限撤销或身份变化后可能需要重新授权。

Apple 相册的真实图库授权、系统五星数量核对、本机原件统计，以及云端读取的启动/取消已实测。完整云端批次和 PhotoKit Live Photo/RAW 配对仍未做专项端到端验证。详细证据见 [验证记录](docs/validation.md)。

## 设计与后续

仓库仅包含代码、文档与应用图标。`build/`、`artifacts/`、本地凭据和缓存均不提交；照片审计结果（包含路径、拍摄时间等元数据）应保存在 `artifacts/` 内。运行独立核查脚本的示例：`python3 scripts/cross-check-focal.py /path/to/photos --output artifacts/audit-local`，需另行安装 ExifTool。

[开源调研、统计口径与产品设计](docs/research-and-design.md)记录了参考项目、算法与后续指标建议。首版聚焦焦段和镜头，机身/日期筛选、镜头 × 光圈、变焦端点使用率、两组照片对比尚未实现。
